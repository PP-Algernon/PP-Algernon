## 🚀 Featured Projects

### 🎯 [二级倒立摆智能控制](https://github.com/PP-Algernon/Double-cartpole-control)

**智能控制课程作业・Python**

针对二级倒立摆这一典型的欠驱动、强耦合、非线性不稳定系统，研究并实现了两种智能控制方案：

- **BP\-PID 自适应控制**：将多维状态压缩为综合误差，用 BP 神经网络在线整定 PID 增益

- **深度强化学习（SAC）控制**：基于 Soft Actor\-Critic 算法实现端到端控制

- **仿真环境**：基于 Pymunk 物理引擎构建 Gymnasium 仿真环境

- **完整框架**：提供完整的实验复现代码与对比分析框架

> 📊 涵盖系统建模、控制器设计、仿真验证、结果分析全流程
